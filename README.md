# Crush Medical Debt

Local copy of crushmedicaldebt.com, organized as a static site.

The page map from the statement of work is in `SITE-PLAN.md`.

Preview locally:

```bash
npm install
npm run dev
```

Then open http://localhost:3000

```
index.html          Homepage
pages/              Site pages
pages/blog/         Articles
assets/images/      Photos, logos, icons
assets/css/         Styles
assets/js/          Scripts
assets/fonts/       Fonts
assets/pdfs/        Downloadable PDFs
```
